# Ёлка со снежинками

Конструктор бумажных снежинок: вырезаешь на сложенном листе, лист разворачивается, к снежинке добавляется подпись «Чему я научился в этом году» и её можно повесить на ёлку.

Один файл `index.html` без сборки и зависимостей. На GitHub Pages ёлка локальная: общая база снежинок работает только на claude.ai.
